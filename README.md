# 파이오니아 선샤인

BNI 부산 파이오니아 챕터의 선샤인 · 파워팀 · 결원 업종 지도.

- **1 나의 선샤인** — 핵심고객을 중심에 놓고 상생직군 6~8개를 배치. 챕터에 있는 업종은 실선 카드, 없는 업종은 점선 카드.
- **2 파워팀** — 경청표 기준 7개 팀(교육 / 법률·기업도움 / 미정 / 공간 / 기업 / 뷰티 / 선물)의 공유 핵심고객과 결원.
- **3 챕터 전체 지도** — 팀별 충원율과 유레카 보드(초대 우선순위).

## 데이터 기준
