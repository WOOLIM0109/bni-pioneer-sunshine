# 9기 협업팀 로컬 검증 결과

검증일: 2026-09-29. 운영 SQL, 실제 가입·이메일·AI 호출, Edge 배포, Git push는 실행하지 않았습니다. 브라우저 검사는 외부 요청을 차단한 메모리 데이터, SQL 검사는 로컬 PGlite를 사용했습니다.

| 범위 | 결과 |
|---|---|
| 브라우저 | 기존·신규 전체 91개 통과. 소속 해제 후 단톡방 캐시 제거 검사 1개를 추가하고 관련 협업팀 14개 및 오프라인 검사를 재실행해 통과. 현재 총 92개 항목 검증. |
| Edge 분석 함수 | 외부 API를 호출하지 않는 46개 검사 통과. 팀·역할 제안 제외와 새 클라이언트 헤더 허용 포함. |
| 수동 SQL 적용·협업팀·롤백 | 로컬 64개 검사 통과. 32명 전/후 대조, 변경 감지, 백업, 역할별 권한, 전체 복구 포함. |
| 기존 DB 기능 회귀 | 권한·단일 문서 165개, 통합 검토 42개, 리퍼럴 공유 41개 통과. |
| 정적 페이지 | 4개 화면·홈·메타정보·기존 주소 이동·인증 해시 유지 검사 통과. |
| 시드 | 33명 dry-run 및 가짜 fetch를 이용한 삽입 경로 검사 통과. 운영 DB 주입 없음. |
| 화면 | 1440px·400px의 협업팀 목록, 관리자 폼, 소속 매트릭스 6장 생성. 대표 화면을 직접 열어 확인. |

로컬 SQL 적용 후 `33 - 1 + 1 = 33명`, 팀별 `4/10/9/5/5명`, 초기 무소속·복수 소속·미등록 이름 각 0명을 확인했습니다. 김철홍은 원본 백업에 남고, 이은성은 B2B 기업지원, 이소연은 웰니스에 들어갑니다. 이서원은 생성하지 않습니다.

롤백 검사에서는 원본 33명의 UUID와 모든 필드, 기존 함수 5개의 정의가 백업과 정확히 일치했습니다. 롤백 직전의 관리자 수정 내용·단톡방·복수 소속·미등록 이름도 별도 비공개 백업에 남습니다. 새로 연결된 자료가 있는 이은성을 지우려는 롤백, 오래된 백업으로 적용, 중복 실행은 차단됩니다.

이전 화면의 조회는 0번 적용 직후와 협업팀 설치 후 모두 확인했습니다. 이전 화면의 신규 등록·폐기된 team 쓰기는 거부하며 AI 분석·반영은 전환 중 잠시 중단해야 합니다. 자세한 실행 순서와 단계별 조회 쿼리는 [운영 반영 안내](9th-collab-release.md)를 따릅니다.

로컬 검증은 실제 운영 SQL 실행·배포 후 확인을 대신하지 않습니다. 운영 반영은 안내서에 따라 사용자가 SQL을 실행하고 조회 결과를 확인한 뒤, 별도 배포 승인을 받아 진행합니다.
